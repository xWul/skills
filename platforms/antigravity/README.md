# Antigravity adapter

Antigravity App/IDE loads global skills at `~/.gemini/config/skills/`; Antigravity CLI loads global skills at `~/.gemini/antigravity-cli/skills/`. Both support workspace-local `.agents/skills/`. The installer supports both targets.

Invoke `/conversion-copywriter` in compatible Antigravity interfaces, or ask the agent to use the skill. There is no claim of a portable subagent configuration; use the skill workflow for conversion audits.
