# Cursor adapter

Cursor supports the shared Agent Skills `SKILL.md` in `~/.agents/skills/` or `~/.cursor/skills/` (local), and in project `.agents/skills/` or `.cursor/skills/`. The universal installer installs to `~/.cursor/skills/` explicitly, supporting Cloud Agents sync if enabled.

The `conversion-strategist` specialist is expressed as a skill workflow, not a cross-platform executable subagent. Agent delegation may vary by Cursor version.
