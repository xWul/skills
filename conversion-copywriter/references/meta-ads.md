# Meta Ads playbook

## Before writing

Record conversion objective (e.g. purchases), target audience, level of awareness, budget if supplied, destination URL/page copy, product offer, and placement. Match ad promise with the first screen of the destination.

## Creative matrix

For each ad angle, create:

| Element | Standard |
|---|---|
| Thumb-stop concept | Clear visual or opening line in the first 1-2 seconds, not unrelated shock |
| On-image hook | Legible without relying on tiny text; one concept |
| Primary text | Brief for cold audiences; longer only when explanation adds value |
| Headline | Reinforces the next step or core benefit |
| CTA | Says exactly what happens after the click |
| Format | 4:5 for feed; 9:16 for Reels/Stories when requested |
| Post-click match | Same product, promise, price if shown, and expected destination |

Suggested test angles: *problem*, *desired outcome*, *demonstration*, *education*, *authority*. A creative test should vary a meaningful strategic element; mere word substitutions are weak tests. Start with 3-5 distinct concepts and clearly label hypotheses.

## Outputs for image/video briefs

- Ratio, scene/camera, emotional tone, colors, text hierarchy, safe-area considerations
- Copy written exactly as it should appear; use few short lines
- What not to show (e.g., exaggerated hazards or misleading visuals)
- For video: hook (0-3s), demonstration/proof, offer, CTA, timing

## Responsible performance analysis

CTR diagnoses interest, not purchases. Diagnose the funnel by checking delivery/reach, CTR and CPC, landing page views, checkout starts, purchase events, conversion rate, and event quality when available. Never infer missing results. Distinguish possible tracking error from actual user behavior. Avoid declaring winners on tiny samples or inconsistent attribution windows. Prioritize testing the weak funnel stage.

## Platform-safe writing

Avoid copy that claims knowledge of a person's private/sensitive traits or shames them. Avoid misleading promises and manufactured scarcity. Do not promise legal, medical, child-safety, or financial outcomes.
